# 来源及采用范围

核对日期：2026-09-23。以下为写作方法来源，不是证明本技能能获优或隐藏辅助写作的实验。全部作批判性借鉴，以当前作业要求为准；未复制上游技能代码或长段原文。

## 本地材料

用户提供的第二次上机九份优秀报告、第一次上机三份优秀报告、两张教师评语截图，以及用户自己的报告和题目要求。原件仍在用户项目中，本技能只保存匿名化的写法提炼，见 exemplar-lessons.md。

教师评语明确支持问题记录、通过实践加深理解、思路与复杂度分析；“总结特别重要”是用户观察与样例比较形成的方向，没有官方权重。样例之间也存在短结论、长反思和逐题总结等多种形式。

## 大学官方写作指南

1. [University of Edinburgh — What? So what? Now what?](https://reflection.ed.ac.uk/reflectors-toolkit/reflecting-on-experience/what-so-what-now-what)
   - 采用：从经验提炼意义，并落实为具体后续行动。
   - 调整：只作为内部追问，不要求正文出现三个固定标题，也不强迫描述情绪。

2. [University of Waterloo — Critical Reflection](https://uwaterloo.ca/writing-and-communication-centre/critical-reflection)
   - 采用：先分析假设与课程联系，再围绕主要认识组织反思。
   - 调整：先前信念须有作者材料；不能为了认知转折编造误解，也不强加社会议题框架。

3. [UNSW — How to write a lab report](https://www.unsw.edu.au/student/managing-your-studies/academic-skills-support/toolkit/writing/engineering-science/report/lab-report)
   - 采用：区分所做工作、观察结果与结果意义，结论回应实验目的。
   - 调整：通用实验报告与个人反思的人称要求不同；按章节和课程规则选择，不强行套用自然科学的仪器或试剂结构。

4. [Monash University — Approaching a reflective or reflexive writing task](https://www.monash.edu/student-academic-success/excel-at-writing/annotated-assessment-samples/arts/arts-reflective-writing-in-arts/approaching-a-reflective-or-reflexive-writing-task)
   - 采用：连接经验、已有知识与新理解，个人判断也需要依据。
   - 调整：艺术课程示例不直接移植为技术课的评价规范；保持本题需要的分析尺度。

## 已读取的公开写作 skills

5. [ComposioHQ — content-research-writer](https://github.com/ComposioHQ/awesome-claude-skills/blob/master/content-research-writer/SKILL.md)
   - 采用：根据读者组织提纲、改进开头、逐段反馈并保留作者声音。
   - 不采用：营销式悬念、夸张吸引语、号召行动和示例里的虚构数据。报告开头以本题具体问题引起兴趣。

6. [softaworks — writing-clearly-and-concisely](https://github.com/softaworks/agent-toolkit/blob/main/skills/writing-clearly-and-concisely/SKILL.md)
   - 采用：段落围绕明确主题、语言具体、删除冗余。
   - 不采用：把英文语法标点规则直接套到中文，或把简洁误解为删掉解释与证据。

7. [blader — humanizer](https://github.com/blader/humanizer/blob/main/SKILL.md)
   - 采用：保留原意与作者声音，检查夸饰、机械节奏、聊天残留和空洞结尾。
   - 不采用：把语言习惯当作者身份检测器、硬性标点禁令或虚构个性细节。本技能不输出“AI 概率”。

## 融合方式

本地样例提供课程语境与有效表达；大学指南补足反思和结论的概念框架；公开 skills 提供编辑流程。goodWriter 将其改写为当前任务可执行的选材、推理、表达与自审方法，不要求安装或运行任何上游仓库。
